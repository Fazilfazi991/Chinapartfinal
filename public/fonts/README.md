# Original brand fonts, served locally

Downloaded 3 October 2026 from official Google Fonts assets, preserving the demo's families/styles/weights. Runtime pages no longer call Google Fonts. The stylesheet is in `app/fonts.css`; all original script subsets are retained.

- DM Mono v16, normal 400/500: `https://fonts.gstatic.com/s/dmmono/v16/`; license `dmmono-OFL.txt`.
- Manrope v20, normal variable 400–800: `https://fonts.gstatic.com/s/manrope/v20/`; license `manrope-OFL.txt`.
- Playfair Display v40, normal/italic variable 600–700: `https://fonts.gstatic.com/s/playfairdisplay/v40/`; license `playfairdisplay-OFL.txt`.

Source CSS request: https://fonts.googleapis.com/css2?family=DM+Mono:wght@400;500&family=Manrope:wght@400..800&family=Playfair+Display:ital,wght@0,600..700;1,600..700&display=swap

Licenses were retrieved from the official google/fonts repository's `ofl/dmmono/OFL.txt`, `ofl/manrope/OFL.txt` and `ofl/playfairdisplay/OFL.txt` through the public GitHub API. Fonts are unmodified WOFF2 files under SIL Open Font License 1.1; retain attribution/license files with redistribution. No font package or runtime service was installed.
